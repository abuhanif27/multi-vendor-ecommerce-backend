Architecture

Request flow from client to domain services

The API keeps external clients on versioned REST routes, delegates authentication to JWT, documents contracts through OpenAPI, and routes business workflows into focused Django apps. Celery handles background work, Redis backs caching and queueing, and PostgreSQL stores transactional data.

  1. Client Web / Mobile
  2. Gateway /api/v1/
  3. Auth JWT
  4. Services Django Apps
  5. Data PostgreSQL
